翻翻花园 · Mac 桌面版

适用机型：Apple 芯片 Mac（M 系列）。

使用方式：解压“翻翻花园-Mac.zip”后，双击“翻翻花园.app”即可打开，也可以将它拖到“应用程序”文件夹。
应用内置全部游戏资源，无需浏览器、网络或额外安装依赖。

开始挑战后，全部卡片会展示 5 秒；盖回之后才开始计时。
每个新关卡均有 5 秒记忆时间，期间不可操作卡片。
支持单人挑战、双人同屏对战，以及 4×4、6×6、8×8 三关。
单人每关初始 60 秒；成功加时间，失败扣时间。
玩法详情可点击窗口右上角“怎么玩”。

此版本为本机编译的应用，未使用 Apple Developer ID 签名和公证。
